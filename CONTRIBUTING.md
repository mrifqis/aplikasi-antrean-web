# Berkontribusi

Issue dan pull request diterima untuk perbaikan bug, aksesibilitas, dokumentasi, dan peningkatan fitur yang tetap menjaga aplikasi ringan.

1. Fork repositori dan buat branch dari `main`.
2. Jangan sertakan `config.php`, dump database, kredensial, atau data produksi.
3. Jalankan pemeriksaan sintaks PHP dan JavaScript.
4. Jelaskan perubahan, cara menguji, dan dampaknya pada instalasi lama di pull request.

Untuk perubahan skema, sertakan jalur migrasi yang aman dan tidak menghapus histori tiket.
